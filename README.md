# Free browser tools for gamers

Free tools and mini games that run in the browser, built for [yuvalgg.com](https://yuvalgg.com).

## Sensitivity and aim
- [Overwatch sensitivity converter](https://yuvalgg.com/tools/overwatch-sensitivity-converter)
- [CS2 to Valorant](https://yuvalgg.com/tools/cs2-to-valorant-sensitivity), [Valorant to CS2](https://yuvalgg.com/tools/valorant-to-cs2-sensitivity), [CS2 to Overwatch](https://yuvalgg.com/tools/cs2-to-overwatch-sensitivity)
- [FOV converter](https://yuvalgg.com/tools/fov-converter)
- [Reaction time test](https://yuvalgg.com/tools/reaction-time-test), [Click speed test](https://yuvalgg.com/tools/click-speed-test)
- [Mouse polling rate tester](https://yuvalgg.com/tools/mouse-polling-rate-tester), [Mouse raw input test](https://yuvalgg.com/tools/mouse-raw-input-test)
